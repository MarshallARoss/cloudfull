# Cloudfull

Cloudfull is a one-screen, vertical feed of your own photos and videos. Swipe
through your library and act on each item with a simple set of tools:

- **Keep** the ones you want to hold on to.
- **Share** the ones you want to send.
- **Shrink** large videos to save space, without deleting them.
- **Delete** the rest — safely, through a Bin, so nothing is lost by
  accident.

There is no account and no sign-in. Your photos and videos never leave your
device, except that a place-name caption (such as "Encino, CA") sends that
photo's own embedded coordinate to Apple Maps to look up the name. Cloudfull
does collect anonymous usage counts through CloudKit, to understand how the
app is used. See [ANALYTICS_DOC.md](ANALYTICS_DOC.md) for exactly what is
counted, and [our privacy policy](https://cloudfull.app/privacy/) for the
full statement.

## Building from source

Cloudfull needs Xcode 26 or later and an iOS 26 simulator. Open
`Cloudfull.xcodeproj` and run. See [CONTRIBUTING.md](CONTRIBUTING.md) for
full build instructions, including what to change to run on your own
device, and how to run the UI test suite.
