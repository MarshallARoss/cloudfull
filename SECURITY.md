# Security

## Report a vulnerability

Do not report security problems in public issues.

Use GitHub's private reporting:

1. Go to the [Security tab](https://github.com/MarshallARoss/cloudfull/security) of this repository.
2. Click **Report a vulnerability**.
3. Describe the problem, the affected version, and the steps to reproduce it.

If you cannot use GitHub, email fluffy@cloudfull.app.

You get a reply within 7 days. Please give us a reasonable time to fix the problem before you disclose it.

## Supported versions

Only the latest version on the App Store and the `main` branch get security fixes.

## Scope

In scope: the Cloudfull iOS app code in this repository and the website in `docs/`.

Out of scope: Apple services that the app uses (PhotoKit, CloudKit, Apple Maps). Report those to Apple.
