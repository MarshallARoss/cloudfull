# M3/M5 seed fixtures

Every `.mp4` in this directory is generated by `scripts/make_seed_clip.sh` and
re-validated on every gate run by `scripts/seed_m3.sh`'s `validate_fixture`
(M5_SPEC §6.2.2). **Do not hand-edit or hand-replace any file here.**

If a file is missing, or fails its per-kind check (dimensions, codec,
pixel format, HDR color tags, size ceiling, or `creation_time` stamp),
`validate_fixture` regenerates it automatically from `make_seed_clip.sh` and
re-checks once. A second failure aborts the seeding run loudly rather than
silently seeding a fixture that no longer matches spec.

| File | Kind |
|---|---|
| `hi_4k_1.mp4`, `hi_4k_2.mp4`, `hi_4k_3.mp4` | `4k` — high-entropy 4K H.264 |
| `hi_4k_hdr.mp4` | `hdr` — high-entropy 4K HEVC 10-bit HLG/BT.2020 |
| `lo_4k_efficient.mp4` | `incompressible` — 4K HEVC 10-bit, deliberately tiny (<= 16,600 bytes) |
| `spot_1080p_1.mp4`, `spot_1080p_2.mp4` | `1080p` — filler, never shrinkable |
